Help & Guide

QA Copilot stitches AI test generation, manual recording, bug hunting, accessibility auditing, and export workflows into one sidebar. Use the question-mark button anytime to jump back to this guide.

  • AI generation (see background/index.js) transforms your feature text into test code.
  • Recording modes (handled by background/recording.js + recording/recorder-injected.js) switch between deterministic, exploratory, and deep bug hunting.
  • Bug bundles compile steps, diagnostics, signals, and severity logic for developers.
  • Accessibility & regression capture snapshots, console history, and diff reports whenever you trigger them.
  • Collections & saved tests keep your generated suites ready for reuse.
Quick workflow
  1. Describe the feature in the Test Case Generator, select the desired risk level, and hit Generate.
  2. Use Manual Recording to capture UI interactions. Pick Test for deterministic playback, Exploratory for insights, or Bug Hunt for diagnostics.
  3. Stop recording, inspect the session timeline, and leverage assertions or API data before saving.
  4. Export bug bundles or generated code from their dedicated cards; the bug bundle card now surfaces stability score, risks, reproductions, and fixes.
  5. Store favorite suites via Collections or export them straight from the Export tab.
Tips for reliability
Recording modes

Test mode captures all interactions, Exploratory throttles noise and clusters flows, Bug Hunt logs console errors, network failures, and performance anomalies.

Bundle hygiene

Stop immediately after reproducing the issue so the bundle is focused and lightweight.

Diagnostics

Use the card output to see hot signals, risk areas, and suggested fixes before filing a bug.

AI code

Regenerate if your feature text changes, and copy/export from the Generated Code card.
